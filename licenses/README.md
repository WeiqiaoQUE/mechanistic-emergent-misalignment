# Upstream Model Agreements

This directory contains unmodified copies of the upstream agreements and use
policies that apply to model-derived adapters distributed in this repository.
They are included for convenient access by recipients; the official online
versions remain authoritative and may be updated by their publishers.

| Local copy | Official source | Retrieved (UTC) |
|---|---|---|
| `LLAMA_3_1_COMMUNITY_LICENSE.txt` | https://raw.githubusercontent.com/meta-llama/llama-models/main/models/llama3_1/LICENSE | 2026-09-28 |
| `LLAMA_3_1_ACCEPTABLE_USE_POLICY.md` | https://raw.githubusercontent.com/meta-llama/llama-models/main/models/llama3_1/USE_POLICY.md | 2026-09-28 |
| `GEMMA_TERMS_OF_USE.html` | https://ai.google.dev/gemma/terms | 2026-09-28 |
| `GEMMA_PROHIBITED_USE_POLICY.html` | https://ai.google.dev/gemma/prohibited_use_policy | 2026-09-28 |

The Meta sources are distributed as plain text or Markdown. The Google sources
are preserved as complete HTML page snapshots because Google publishes these
terms as web pages. SHA-256 digests for these exact local copies are recorded in
`SHA256SUMS`.

See `../ARTIFACT_TERMS.md` for the mapping from released adapter groups to these
agreements.
